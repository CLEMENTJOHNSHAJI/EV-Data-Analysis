EVs per Infrastructure Capacity Unit

ICS = Type 2 + (3 × CHAdeMO) + (5 × CCS)  |  EVs per Capacity Unit = Total EV Fleet / ICS  |  Lower value = better infrastructure availability

Recommended diagram types: (1) Stacked bar chart to show how weighted charger types build the ICS; (2) Horizontal bar chart to compare the final EVs-per-capacity-unit ratio across cities. Together, these make both the calculation logic and the final comparison easy to understand.
